# Team — Kavtsya (Кавця)

> Who owns what. Created 2026-07-09, when the team doubled.

## Mari (Марі) — co-founder · creative director

Owns everything a person sees and feels:

- **Design** — the app's look (screens, icon, colors, typography); works with Claude
  in the desktop app (Claude Design) on mockups.
- **Brand** — Kavtsya's character: warm, Ukrainian, a little magical. Moodboard,
  logo, brand voice.
- **Marketing** — Instagram @kavtsya, content (Ворожка as the flagship format),
  the «підтримуй свою кав'ярню» positioning, launch.
- **Sales & discovery** — talking to Cafés, the founding-café pilot (first 5–10),
  feedback from CafeOwners (Кавовари).
- **Voice of the Customer** — Ukrainian copy in the app; the final "would I love
  this?" check before anything ships.

## Olek (Олек) — co-founder · tech lead

Owns everything under the hood:

- **Code** — the mobile app (React Native/Expo) and the API (Hono/PostgreSQL).
- **Data & security** — database, QR protection, future payments.
- **AI** — the Ворожка machinery (provider abstraction, prompts, daily batch).
- **Infrastructure** — Railway, CI, releases, keeping it running 24/7.

## Together

Product decisions — what we build, for whom, and why — are made jointly. Design
says what the Customer should feel; tech says how to build it honestly.
Disagreements are settled over a second coffee.

### Working agreements

- Shared MacBook: Olek uses Claude Code in the terminal, Mari uses the Claude
  desktop app.
- Mari's design decisions that affect code (colors, components, flows) are captured
  briefly as GitHub issues labeled `design`; Claude carries them into code.
- The glossary in `CONTEXT.md` is the shared language for everyone: Зернятко,
  Ворожка, CafeOwner (Кавовар), Purchase, Reward.
- Mari's onboarding page (artifact): "Кавця — знайомство для Марі".
